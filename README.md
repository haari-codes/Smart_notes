# 📚 Smart_Notes

### Learn Smart. Remember More.

Smart_Notes is a student-friendly web application
designed to organise study materials and improve learning.

## Features
- Create and manage notes
- Upload PDF documents
- Generate smart summaries
- Create flashcards
- Practice quizzes
- Search saved notes

## Technologies Used
- HTML
- CSS
- JavaScript
